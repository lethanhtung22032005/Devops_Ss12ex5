# Thư mục minh chứng

Đặt ảnh chụp màn hình kết quả pipeline **tích xanh** tại đây với tên
`pipeline-green.png` (được nhúng trong `troubleshooting.md`).

Cách chụp: mở repo trên GitHub → tab **Actions** → chọn lần chạy mới nhất của
workflow **Broken Pipeline (Fixed)** → chụp toàn bộ 2 job đều màu xanh ✅.
